### Put the most important thing on top of the file

A reader should get the point of a file without scrolling.

- In documents, lead with the conclusion, decision, or summary. Put background and details after it.
- In code, put the entry points and exported API first where the language allows. Put helpers and private details below them.
- In configuration, put the settings a reader most likely changes first.
- When adding to an existing file, place the new content where its importance puts it. Do not append it to the end by default.
